Testing jQuery animations in Jasmine

Written in August 2017.

View the CSS for this target

You spotted it. This target is one circle and one gradient:

.test {
  border-radius: 50%;
  background: radial-gradient(circle,
    var(--signal) 0 22%,
    var(--sand) 22.5% 42%,
    var(--roast) 42.5% 70%,
    transparent 70.5%);
}

The simplest, and fastest way is to simply ignore the animations with setting jQuery.fx.off = true and checking for whatever the final result is:

describe('container', function () {
  var container;

  beforeEach(function() {
    jQuery.fx.off = true; // don't wait for animations
    container = $('#some-container-with-animation');
  });

  afterEach(function() {
    jQuery.fx.off = false;
  });

  it('toggling a container with jQuery animation', function () {
    container.toggle('fast');
    expect(container).toBeHidden();
  });
});

In the examle, we’re not testing the animation per se, but we’re testing that the container has been hidden.
